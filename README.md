# To-Do List App

A simple, responsive to-do list web application built with pure HTML, CSS, and JavaScript.

## Reference Open-Source Project

This project was inspired by and compared against the following open-source project:

- Project: simple-todo-list
- Author: tasscoding
- GitHub URL: https://github.com/tasscoding/simple-todo-list

## Project Description

This app allows users to manage their daily tasks through a clean, minimal interface. It was independently implemented using AI coding tools rather than copying the reference project's code, while aiming for comparable functionality and scope.

## Features

1. Add tasks — Type a task and press Enter or click "Add" to add it to the list.
2. Mark tasks as complete — Click the checkbox next to a task to toggle its completed state (shown with a strikethrough).
3. Delete tasks — Click the X button to remove a task from the list.
4. Filter tasks — Switch between "All", "Active", and "Completed" views using the filter buttons.

## Built With

- HTML5
- CSS3
- Vanilla JavaScript (no frameworks or libraries)

## AI Tools Used

- Claude (Anthropic) — used to design, generate, and iterate on the HTML/CSS/JavaScript implementation.

## How to Run

1. Clone this repository: git clone https://github.com/shuang1219/todo-list-app.git
2. Open index.html in any web browser — no installation or build steps required.
